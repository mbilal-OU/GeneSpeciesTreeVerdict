# Roadmap

## v0.1 — transparent diagnostic foundation
- [x] Newick parsing and validation
- [x] explicit gene-to-species mapping
- [x] taxon coverage and copy-number QC
- [x] RF and split comparison for single-copy trees
- [x] species-overlap duplication screen
- [x] rooted LCA duplication-loss diagnostic
- [x] PASS / REVIEW / RESOLVE explanations
- [x] batch reference-split support
- [x] five-scenario 10-genome tutorial
- [x] tests, CI, docs and contribution infrastructure

- [ ] interactive visual report

- [ ] GeneRax adapter
